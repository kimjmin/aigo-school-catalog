# AI:GO 중학교 도우미 모음

Backend.AI GO(AI:GO)에서 바로 설치해 쓸 수 있는 **중학교용 학습 도우미와 모둠 활동 템플릿** 예제 모음입니다.
모든 도우미는 인터넷 검색이나 파일 도구를 쓰지 않고, **맥북 안의 AI 만으로** 동작하도록 만들었습니다(모둠의 삽화 담당만 그림 그리기 도구를 씁니다).

## 들어 있는 것

| 종류 | 이름 | 하는 일 |
|---|---|---|
| 도우미 | 📘 국어 글쓰기 도우미 | 잘한 점 1가지, 고칠 점 2가지. 글을 대신 써 주지 않음 |
| 도우미 | 📐 수학 풀이 도우미 | 정답 대신 단계별 힌트, 반복 실수 짚어 주기 |
| 도우미 | 🗣 영어 회화 도우미 | 틀린 문장 고쳐 주고 이유를 한국어로 짧게 |
| 도우미 | 🔬 과학 탐구 도우미 | 궁금증을 탐구 질문과 관찰 계획으로 |
| 모둠 템플릿 | 🧑‍🤝‍🧑 모둠 탐구 보고서팀 | 모둠장, 자료 조사, 보고서 작성, 삽화, 검토 담당이 나눠서 표지 그림이 있는 탐구 보고서 초안 작성 |
| 파일 예제 | 🏮 조선 시대 장터 해설사 (`airdrop/`) | 파일로 주고받는 도우미 예제. 목록에는 나오지 않고, 가져오기로 설치 |

## AI:GO 에 이 모음 연결하기

1. AI:GO 에서 **설정 → 에이전트 레지스트리 → 소스 추가**
2. 아래 값을 입력하고 **소스 추가**
   - 소유자: `kimjmin`
   - 저장소: `aigo-school-catalog`
   - 브랜치: `main`
   - 표시 이름: `중학교 도우미 모음` (자유)
   - **인증 방법: `없음(익명)`** (다른 값이면 목록이 비어 보입니다)
3. **에이전트 확장** 화면에서
   - **커뮤니티** 탭: 도우미 4개가 보입니다. **설치**를 누르세요.
   - **스쿼드 템플릿** 탭: "모둠 탐구 보고서팀"을 **설치**하세요. 이후 스쿼드 만들기에서 이 템플릿을 고를 수 있습니다.

## 모둠 활동 전에 한 번만 설정

- **설정 → "기본 컨텍스트 길이"를 32768** 로 (모둠은 16384 이상 필요). 바꾼 뒤 채팅 모델을 다시 띄웁니다.
- 삽화 담당을 쓰려면 **설정 → 모델 → 기본 이미지 모델**에 이미지 모델(예: Z-Image Turbo)을 지정합니다.
- 모둠 화면의 "도구가 활성화되지 않은 에이전트가 있음" 안내는 정상입니다. 글만 쓰는 담당은 일부러 도구를 주지 않았습니다.

## 파일 하나로 도우미 주고받기 (AirDrop 등)

1. `airdrop/joseon-market-guide.json` 파일을 받습니다(AirDrop, 메일, USB 모두 가능).
2. AI:GO **에이전트 확장 → 가져오기**에서 그 파일을 고릅니다.
3. "조선 시대 장터 해설사"가 내 도우미 목록에 추가됩니다.

선생님이 직접 만든 도우미도 **내보내기**로 같은 형식의 파일을 만들 수 있습니다.

## 내 학교용으로 고쳐 쓰기

- 이 저장소를 복사(Fork)한 뒤 `helpers/` 의 파일에서 `name`, `description`, `systemPrompt`(도우미에게 주는 수업 원칙)를 고치면 됩니다.
- 새 도우미를 추가했다면 `index.json` 의 `profiles` 목록에 한 줄을 추가합니다. 모둠 템플릿은 `"kind": "squad_template"` 을 붙입니다.
- AI:GO 에서 연결한 저장소를 내 저장소로 바꾸고 **새로고침**하면 목록이 갱신됩니다.

## 참고

- AI 답변은 틀릴 수 있습니다. 사실 확인이 필요한 내용은 교과서와 함께 확인하세요.
- 도우미는 학생의 이름 외 개인 정보를 묻지 않도록 지시되어 있습니다.
- 형식: [AI:GO 에이전트 카탈로그](https://github.com/lablup/agent-catalog) 와 같은 구조입니다.
